# spectral_comparison_2026-09-01

A plain figure deck for the 2026-09-01 spectral-comparison work. **Undesigned by
intent**: one figure per slide, a factual title, an optional one-line caption, and
nothing else. No bullets, no speaker notes, no claim titles.

- `spectral_comparison_2026-09-01.pptx` (29 slides, 25 figures)
- `build_deck.py` regenerates it from `figures/`
- `figures/` holds copies so the deck is self-contained; sources are
  `research/ftir_ec_phase3/output/plots/ftir50|ftir52/` plus the session's
  cross-site crossplots

Sections: (1) Bishoftu and the five sites, (2) spectral comparison methods
(ftir_50), (3) the network spectral map (ftir_52).

When a talk deck is wanted instead, rebuild through the `ann-deck` skill: claim
titles, SAY/NOTES speaker notes, numbers validated against the calibration
explorer. This one is only a figure carrier.
